# Little Steps — Mahima's Daily Habit Tracker

## Included
- Colorful, mobile-first daily checklist for health, GRC, creativity/Fiverr and mindful living
- Daily progress percentage
- Notes and a daily focus field
- Local device storage (no account required)
- Exportable JSON backup
- PWA manifest, service worker and app icons for installation

## Install on Android
A PWA must be served from HTTPS (or localhost) to be installable and to use offline caching. These files are ready to host, but are not hosted automatically.

1. Upload the contents of this folder to a static HTTPS host (for example, GitHub Pages or Netlify).
2. Open the hosted `index.html` URL in Chrome on your Android phone.
3. Open Chrome's ⋮ menu and choose **Install app** or **Add to Home screen**.
4. Follow the prompt. The app icon will appear on your home screen.

## Data and privacy
Checklist state and notes are stored in this browser on this device using localStorage. Clearing Chrome site data or changing browser/device can erase that data. Use **Export backup** regularly if you want a copy. No information is sent to a server by this app.

## Daily reset
Tasks are stored by local calendar date. The next day starts with a fresh checklist while previous dates' local data remain in the browser until site data is cleared.
